🎯 Создание ивента

⚠️ Важно!

Перед началом работы необходимо создать ивент и задать пароль для доступа к статистике.

Зачем нужно создавать ивент?

Создание ивента - это обязательный первый шаг перед началом регистрации участников. При создании ивента вы:

  • Задаете уникальный идентификатор события (event_id)
  • Устанавливаете пароль для защищенного доступа к результатам
  • Обеспечиваете безопасность данных вашего мероприятия

Как создать ивент?

Используйте конфигуратор ссылок ниже на этой странице. В разделе "Создание нового ивента" заполните:

  1. Event ID - уникальный идентификатор вашего события (например: conference2024, meetup-moscow)
  2. Пароль - пароль для доступа к статистике и результатам
  3. Нажмите кнопку "Создать ивент"

💡 Совет

Сохраните пароль в надежном месте! Он понадобится для просмотра результатов и статистики.

Что происходит после создания?

После успешного создания ивента:

  • Система автоматически сгенерирует ссылки для сканирования и просмотра результатов
  • Вы сможете начать регистрацию участников через QR-сканер
  • Доступ к результатам будет защищен паролем
